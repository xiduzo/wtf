# ASD-STE100 rule index (Issue 9, 2025-01-15)

Rule numbers and short statements only. The explanatory text and examples are
copyrighted. Read the standard itself at https://asd-ste100.org.

Part 1 has nine sections and 63 rules. Part 2 is the dictionary: 875 approved
words, plus 1274 not-approved words each with an approved alternative.

## Section 1 — Words (1.1–1.14)

| Rule | Statement |
|------|-----------|
| 1.1 | Use words that are approved in the dictionary, or that qualify as a technical noun or technical verb. |
| 1.2 | Use approved words only as the part of speech the dictionary specifies. |
| 1.3 | Use approved words only with their approved meanings. |
| 1.4 | Use only the approved forms of verbs and adjectives. |
| 1.5 | You can use words that fit one of the 22 technical noun categories. |
| 1.6 | Use an unapproved word only when it is a technical noun or a technical verb. |
| 1.7 | Do not use technical nouns as verbs. |
| 1.8 | Use technical nouns that are approved in your company, industry, or subject field. |
| 1.9 | When you must select a technical noun, use one that is short and easy to understand. |
| 1.10 | Do not use regional, slang, or jargon words as technical nouns. |
| 1.11 | Do not use different technical nouns for the same item. |
| 1.12 | You can use verbs that fit one of the 4 technical verb categories. |
| 1.13 | Do not use technical verbs as nouns. |
| 1.14 | Use American English spelling unless other official directives say otherwise. |

## Section 2 — Multi-word nouns (2.1–2.2)

| Rule | Statement |
|------|-----------|
| 2.1 | Write multi-word nouns of no more than three words. |
| 2.2 | When a technical noun has more than three words, write it in full. |

The head noun is usually the last word. Each extra modifier in front of it adds
one more ambiguous connection the reader must resolve.

## Section 3 — Verbs (3.1–3.7)

| Rule | Statement |
|------|-----------|
| 3.1 | Use only the verb forms given in the dictionary. |
| 3.2 | Use only these forms and tenses: infinitive, imperative, simple present, simple past, simple future, past participle (as an adjective). |
| 3.3 | Use the past participle form as an adjective. |
| 3.4 | Do not use auxiliary verbs to make complex verb constructions. |
| 3.5 | Use the "-ing" form only as a technical noun or as a modifier in a technical name. |
| 3.6 | Use the active voice. In descriptive writing, use the passive voice only if the agent is unknown. |
| 3.7 | Use an approved verb to describe an action, not a noun or other part of speech. |

Not approved: present perfect (`has adjusted`), past perfect (`had adjusted`),
present or past progressive (`is/was adjusting`), and every other complex
construction.

## Section 4 — Sentences (4.1–4.5)

| Rule | Statement |
|------|-----------|
| 4.1 | Write short and clear sentences. |
| 4.2 | Do not omit words or use contractions to make sentences shorter. |
| 4.3 | Use a vertical list for complex text. |
| 4.4 | Use connecting words and phrases to connect sentences with related topics. |
| 4.5 | When applicable, use an article (the, a, an) or a demonstrative adjective (this, these) before a noun or multi-word noun. |

Approved connectors include `and`, `but`, `then`, `thus`, `as a result`, `at the
same time`. Demonstrative adjectives also work as connectors.

## Section 5 — Procedural writing (5.1–5.5)

| Rule | Statement |
|------|-----------|
| 5.1 | Write short sentences. Maximum 20 words per sentence. |
| 5.2 | Write only one instruction per sentence, unless two or more actions occur at the same time. |
| 5.3 | Write instructions in the imperative (command) form. |
| 5.4 | When a condition must be known first, start the instruction with that condition. |
| 5.5 | Write notes only to give information, not instructions. |

Simultaneous actions may share a work step but should still be split into two
sentences if the combined sentence exceeds 20 words.

## Section 6 — Descriptive writing (6.1–6.6)

| Rule | Statement |
|------|-----------|
| 6.1 | Give information gradually. |
| 6.2 | Use key words and key phrases to give the text a logical structure. |
| 6.3 | Write short sentences. Maximum 25 words per sentence. |
| 6.4 | Use paragraphs to show related information. |
| 6.5 | Make sure each paragraph has only one topic. |
| 6.6 | Make sure no paragraph has more than six sentences. |

## Section 7 — Safety instructions (7.1–7.3)

| Rule | Statement |
|------|-----------|
| 7.1 | Use an applicable word ("warning", "caution") or symbol to identify the level of risk. |
| 7.2 | Start a safety instruction with a clear and accurate command or condition. |
| 7.3 | Give an explanation to show the risk or the possible result. |

Risk triage:

- Risk of injury or death → **warning**.
- Risk of damage to machines, tools, or equipment → **caution**.
- Both levels together → **warning**.

STE gives no formatting rules. Uppercase in the standard's examples is a
convention of the examples, not a rule.

## Section 8 — Punctuation and word count (8.1–8.7)

| Rule | Statement |
|------|-----------|
| 8.1 | You can use all standard English punctuation marks, but not the semicolon (;). |
| 8.2 | Use hyphens (-) to connect words that are directly related. |
| 8.3 | You can use parentheses for references, item identifiers, work-step identifiers, abbreviations, singular/plural forms, explanations, and alternatives. |
| 8.4 | In a vertical list, a colon (:) counts like a period and ends a sentence. |
| 8.5 | Text inside parentheses counts as one word. |
| 8.6 | Count each of these as one word: numbers; numbers with units; abbreviations; alphanumeric identifiers; quoted text; titles, headings, placards, and labels; proper nouns of individuals, groups, organizations, and geopolitical entities. |
| 8.7 | Hyphenated words count as one word. |

The semicolon is the only banned mark. The em dash is not banned. STE gives no
general punctuation rules beyond these and defers to style guides such as the
Chicago Manual of Style.

## Section 9 — Writing practices (9.1–9.4)

| Rule | Statement |
|------|-----------|
| 9.1 | Use a different sentence construction when a word-for-word rewrite is not possible. |
| 9.2 | Use each approved word correctly. |
| 9.3 | When you use two words together, do not make phrasal verbs. |
| 9.4 | When you select terminology or wording, use a consistent style. |

Phrasal verbs carry a concrete meaning and an abstract meaning. Both parts can
be approved words while the pair is not: `put out` → `extinguish`, `give off` →
`release`, `spin up` → `start`.

## Technical name and technical verb categories

Rule 1.5 lists 22 technical noun categories (parts and design items; vehicles,
machines and locations on them; and so on). Rule 1.12 lists 4 technical verb
categories, the first being manufacturing processes. Both are escape hatches:
they let domain terminology in without opening the dictionary.
