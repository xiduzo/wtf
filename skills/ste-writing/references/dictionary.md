This file is large. Grep it for a word, do not read it whole.

Parts of speech: n, v, adj, adv, prep, conj, pron, art, pref.
TN = technical noun, TV = technical verb (domain terms, not dictionary words).

## How to use it

1. Look the word up in **Not approved** first. If it is there, use one of the
   listed alternatives.
2. If it is not there, check **Approved**. A word absent from both lists is
   only usable as a technical noun or technical verb (Rules 1.5, 1.12).
3. An approved word is approved for the listed part of speech only (Rule 1.2)
   and for its dictionary meaning only (Rule 1.3).
4. For approved verbs, the listed inflections are the only approved forms
   (Rules 1.4, 3.1).
